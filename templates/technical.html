What is the difference between a list and a tuple in Python?
Python
Answer:

A list is mutable, which means its elements can be changed after creation. A tuple is immutable, meaning its elements cannot be changed after creation.

Lists use square brackets [ ], while tuples use parentheses ( ).

2
What is Object-Oriented Programming?
Programming
Answer:

Object-Oriented Programming (OOP) is a programming approach based on objects and classes.

The major concepts of OOP include Encapsulation, Inheritance, Polymorphism and Abstraction.

3
What is a database?
DBMS
Answer:

A database is an organized collection of data that can be stored, accessed, managed and updated efficiently.

Examples include MySQL, SQLite, PostgreSQL and Oracle Database.

4
What is Machine Learning?
Machine Learning
Answer:

Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

5
What is the difference between supervised and unsupervised learning?
Machine Learning
Answer:

In supervised learning, the model is trained using labelled data.

In unsupervised learning, the model works with unlabelled data and tries to discover patterns or groups.
